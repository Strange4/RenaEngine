# RenaEngine

**An Open-Source game engine designed for programming strategy competitions.
Make your bot programming competitions come true!**

Used by: <img width="75" height="82" alt="image" src="https://github.com/user-attachments/assets/b0700777-0320-4145-b1a5-934be969bf63" /> 
<br> Concordia's Game Development Club (CGD)


## 📖 Project Summary
RenaEngine is a game engine designed specifically for making programming strategy competitions. Think terminal by Citadel or battlecode by MIT, which are 2D grid agent programming strategy competitions that are solely controlled and played out by code.
